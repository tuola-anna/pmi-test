# Frontend Skill

## Goal (Цель)
Создание интерактивной одностраничной веб-страницы (Single Page). 
Пользователь должен иметь возможность через UI-ползунки менять макроэкономические параметры и мгновенно видеть результат прогноза PMI и его визуализацию без перезагрузки страницы.

## Tech Stack (Стек технологий)
*   **Язык:** Vanilla JS (Чистый JavaScript, ES6+). Запрещено использование React, Vue, Angular или других фреймворков.
*   **Сборка:** Не требуется (Static Site). Запуск через открытие `index.html` в браузере или через `Live Server`.
*   **Визуализация:** Chart.js (подключается через CDN)Зависимость PMI от индикаторов. Выбор индикатора организовать в отдельном выпадающем списке
*   **Стилизация:** CSS с использованием методологии **BEM** (Block Element Modifier).

## Architecture & Structure (Структура файлов)
src/frontend/
 ├── index.html # Разметка: ползунки (input type="range"), поля вывода, контейнер для графика.
 ├── css/
 | ├──style.css # Стили. Именование классов строго по BEM.
 ├──js/ 
   ├─── script.js # Логика: работа с DOM, запрос к API, отрисовка графика.

## Styling Rules (BEM & CSS)
1.  **Методология:** Строго BEM.
    *   Блок: `.slider-block`
    *   Элемент: `.slider-block__label`
    *   Модификатор: `.slider-block--active`
2.  **Цвета:** Использовать переменные CSS (`:root`) или жестко соблюдать палитру из `SKILL.md`:
    *   `--color-success: #28a745;` (PMI > 50)
    *   `--color-danger: #dc3545;` (PMI < 50)
3.  **Адаптивность:** 
    *   Использовать `meta viewport`.
    *   На мобильных устройствах (width < 768px) форма со слайдерами должна перестраиваться в один столбец.

## JavaScript Logic (Vanilla JS)
1.  **Работа с API:**
    *   Использовать `Fetch API` с методом `POST` на эндпоинт `/predict`.
    *   Заголовки: `'Content-Type': 'application/json'`.
    *   **Обработка ошибок:** Если сервер вернул статус не 200, вывести текст ошибки в UI.
2.  **Динамика (Reactivity):**
    *   При каждом изменении `input` (ползунка) должен происходить вызов функции `updateDashboard()`.
    *   Функция `updateDashboard()` собирает данные со всех слайдеров, отправляет их в API и обновляет интерфейс.
3.  **Визуализация (Chart.js):**
    *   Инициализация графика происходит один раз.
    *   При новых данных **не пересоздавать** график, а использовать метод `chart.update()`.
    *   **Цвет линии/точки:** Должен зависеть от значения PMI (зеленый если > 50, красный если < 50).
4.  **Валидация:** 
    *   Использовать встроенные атрибуты `min`, `max`, `step` в HTML.
    *   Дополнительно проверять данные перед отправкой в JS.

## Forbidden (Запрещено)
*   Использование `document.write`.
*   Использование `var` (только `let` и `const`).
*   Использование библиотек UI (jQuery, Bootstrap JS).
*   Хардкод URL бэкенда в коде (URL должен быть относительным `/predict` или браться из конфига, если фронтенд вынесен отдельно).
