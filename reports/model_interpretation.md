# Интерпретация результатов модели PMI

## 1. Метрики качества модели

Модель предсказывает значение **PMI (Purchasing Managers' Index)** — индекса деловой активности. PMI > 50 означает расширение экономики, PMI < 50 — сокращение.

### RMSE (Root Mean Squared Error) — 2.8549

**Что это:** Корень из среднеквадратичной ошибки. Показывает среднюю величину ошибки предсказания в тех же единицах, что и целевая переменная (PMI).

**Как читать:**
- RMSE = 2.85 означает, что в среднем модель ошибается на ~2.85 пункта PMI
- RMSE чувствителен к большим ошибкам (выбросам) — если есть случаи с крупной ошибкой, RMSE будет выше
- Чем ниже RMSE, тем лучше

**Контекст:** Поскольку PMI измеряется в диапазоне примерно 35–65, ошибка в 2.85 пункта — это около 5–8% от размаха данных. Это умеренный результат.

### MAE (Mean Absolute Error) — 2.3160

**Что это:** Средняя абсолютная ошибка. Показывает среднее расстояние между предсказаниями и реальными значениями.

**Как читать:**
- MAE = 2.32 означает, что среднее предсказание отличается от факта на ~2.3 пункта PMI
- В отличие от RMSE, MAE не усиливает влияние больших ошибок
- MAE всегда ≤ RMSE (если есть вариация в ошибках)

**Сравнение с RMSE:** Разница между RMSE (2.85) и MAE (2.32) небольшая — это говорит о том, что больших выбросов-ошибок нет, распределение ошибок равномерное.

### MAPE (Mean Absolute Percentage Error) — 4.95%

**Что это:** Средняя абсолютная ошибка в процентах. Показывает, на сколько процентов в среднем модель ошибается относительно реального значения.

**Как читать:**
- MAPE = 4.95% означает, что в среднем предсказания отклоняются от факта на ~5%
- MAPE легче воспринимается не-техническими специалистами
- MAPE < 10% считается хорошим результатом для экономических данных

**Ограничение:** MAPE не определён, если реальное значение = 0. В нашем случае PMI всегда > 35, поэтому метрика корректна.

### Сводная таблица

| Метрика | Значение | Что означает | Оценка |
|---|---|---|---|
| RMSE | 2.85 | Средняя ошибка в пунктах PMI | Умеренная |
| MAE | 2.32 | Медианная ошибка в пунктах PMI | Умеренная |
| MAPE | 4.95% | Средняя ошибка в процентах | Хорошая |

## 2. SHAP-график (Beeswarm Plot)

SHAP (SHapley Additive exPlanations) показывает, **каждый признак влияет на предсказание** — в какую сторону и насколько сильно.

### Как читать график

Каждая точка — это одно наблюдение (строку данных).

| Элемент графика | Значение |
|---|---|
| **Ось X** | SHAP value — влияние признака на предсказание |
| **Ось Y** | Признаки, отсортированные по важности |
| **Цвет точки** | Значение признака (красный = высокое, синий = низкое) |

### Разбор оси X (SHAP value)

```
        Низкое предсказание PMI    |    Высокое предсказание PMI
                 ←-----------------|-----------------→
               -0.5               0               +0.5
```

- **SHAP > 0** (правая сторона) — признак **повышает** предсказание PMI
- **SHAP < 0** (левая сторона) — признак **понижает** предсказание PMI
- **SHAP ≈ 0** — признак практически не влияет на это предсказание

### Разбор цвета точек

```
Высокое значение признака  ←  Низкое значение признака
       🔴🟠🟡              ⚪              🔵🟣⬛
```

- **Красный** = высокое значение признака для данного наблюдения
- **Синий** = низкое значение признака

### Практическая интерпретация

Если вы видите кластер красных точек `inflation` справа (SHAP > 0):
→ **Высокая инфляция повышает предсказание PMI** для этих наблюдений

Если синие точки `key_rate` слева (SHAP < 0):
→ **Низкая ключевая ставка понижает предсказание PMI**

### Приоритет признаков

Признаки отсортированы по вертикали **по степени влияния**:
- **Вверху** — самые важные признаки (больший разброс SHAP values)
- **Внизу** — наименее важные (точки сгруппированы близко к 0)

Это позволяет аналитикам быстро понять, на какие макроэкономические факторы модель обращает внимание в первую очередь.

## 3. Структура пайплайна

Модель использует `sklearn Pipeline`, который гарантирует воспроизводимость и защищает от утечки данных:

```
Исходные данные
     │
     ▼
┌─────────────┐
│ RobustScaler│  ← Масштабирует признаки (устойчив к выбросам)
└──────┬──────┘
       ▼
┌──────────────────────┐
│ FeatureInteraction   │  ← Создаёт: inflation × key_rate
└──────┬───────────────┘
       ▼
┌────────────────────┐
│ CatBoostRegressor  │  ← Финальное предсказание PMI
└────────────────────┘
```

**Почему Pipeline важен:**
- Скейлер и модель обучаются на train-данных и применяются к test-данным
- Нет утечки статистик из test-сеты в train-сет
- Для предсказания нового наблюдения достаточно одного файла `model.pkl`

## 4. Как использовать модель

Сохранённый файл `model.pkl` содержит весь пайплайн целиком:

```python
import joblib

# Загрузка
model = joblib.load("model.pkl")

# Предсказание
prediction = model.predict(new_data)
```

Где `new_data` — DataFrame с колонками:
`inflation`, `key_rate`, `oil_price`, `consumer_confidence`, `inflation_lag1`, `oil_price_lag1`
